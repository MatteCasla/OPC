# OPC
Programa con la funcion de monitoreo de datos de la computadora.
Cuenta con funciones para revisar en tiempo real el consumo de la CPU, RAM y el porcentaje de uso del disco.

Tambien tiene apartados de automatizacion donde se avisa al usuario que procesos superan cierta cantidad de consumo y ademas para un mayor control tambien cuenta con un apartado de logs.
Dentro de los logs puedes encontrar historial de acciones, logeo de procesos en el momento que el usuario desee y la opcion de habilitar / deshabilitar un sistema que cada 5 minutos hace un reporte de procesos clasificandolos en consumo medio o alto.
